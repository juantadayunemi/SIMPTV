🔊 Generador de Sonidos TrafiSmart

Instrucciones: Usa los botones para probar diferentes tonos. Una vez que encuentres el que te guste, puedes grabar tu pantalla con audio o usar software de captura de audio para guardar el sonido como MP3.

🔔 DEFAULT (NONE, LOW)

Notificación suave - 1 beep corto

⚠️ ALERT (MEDIUM)

Atención moderada - 2 beeps

🔴 URGENT (HIGH)

Urgente - 3 beeps rápidos

🆘 ALARM (CRITICAL)

Alarma crítica - Sirena continua

Nota: Para usar estos sonidos en producción:
  1. Descarga sonidos profesionales de sitios como Freesound.org o Zapsplat.com
  2. O graba estos tonos usando software de captura de audio (ej: Audacity)
  3. Convierte a MP3 y guárdalos en esta carpeta con los nombres correctos
  4. Archivos necesarios: default.mp3, alert.mp3, urgent.mp3, alarm.mp3
